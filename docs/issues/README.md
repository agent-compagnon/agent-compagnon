# Issues MCP Proxy

Ces fichiers sont les issues du projet, rédigées à l'issue du cadrage. Ils sont ici parce que la création
d'issues sur GitHub a été refusée à l'intégration (`403 Resource not accessible by integration`). Dès que
l'application GitHub dispose du droit d'écriture sur les Issues, chaque fichier devient une issue (titre = première
ligne), rattachée à l'issue de cadrage, et ce dossier peut être supprimé.

`00-cadrage.md` est la référence commune : chaque issue suppose qu'elle a été lue.
